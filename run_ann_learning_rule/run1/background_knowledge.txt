Background Knowledge for Task: Block-Diagonal RTRL + Exponential Decay (Combined)

PURPOSE:
We established that:
- Full RTRL with decay=0.8 → 95.1% (but O(n³) — too expensive)
- Block-diagonal K=16 alone → 41.1% (O(n×K²) — cheap but insufficient)
- Block-diagonal K=32 alone → 78.8%

Hypothesis (H18): combining block-diagonal WITH exponential decay might synergize.
The decay preserves attenuated long-range temporal info, which might partially compensate
for the missing cross-block spatial paths.

ALGORITHM:
- Partition n=64 neurons into n/K blocks of size K
- Within each block, maintain and propagate the full K×K×K Jacobian
- Apply exponential decay to the block Jacobians each step
- Use random feedback B for the learning signal
- Ignore cross-block Jacobian entries entirely

The block Jacobian update becomes:
  J_block_new[i,j,k] = decay * phi'(a_i) * (W_block[i,:] @ J_block[:,j,k] + delta(i==j)*h_block[k])

where W_block is the within-block recurrent weight sub-matrix.

COMPLEXITY: O(n × K²) per step (same as block-diagonal without decay)
The decay just multiplies each entry — doesn't change asymptotic cost.

EXPERIMENTAL PLAN:
Test the 2D grid:
- Block size K = {8, 16, 32}  (from Exp05: K=8→31%, K=16→41%, K=32→79%)
- Decay = {0.8, 0.9, 0.95}  (from Exp06: full-RTRL with decay=0.8→95%, 0.9→99.8%)
- Also include K=64 (full) with decay=0.9 as reference

If K=16 + decay=0.9 reaches >80%, that's a viable algorithm:
- Memory: O(n × K²) = O(64 × 256) = 16,384 entries (vs 262,144 for full RTRL)
- 16× cheaper than full RTRL
- Biologically motivated: local circuits with decaying eligibility traces
