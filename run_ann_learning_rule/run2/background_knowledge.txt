DIAGNOSIS:
Our eligibility trace implementation differs from standard e-prop in critical ways:
1. e-prop eligibility: e_ij(t) = alpha * e_ij(t-1) + dh_i/dz_i * h_j(t-1)
   - This is just the LOCAL derivative: post-synaptic sensitivity * pre-synaptic activity
   - The trace accumulates over time with decay alpha
   - Crucially, e-prop uses the DERIVATIVE of the post-synaptic neuron's output
     w.r.t. its TOTAL input, times the pre-synaptic activity

2. Our implementation uses: post_deriv * pre * G_m (phase kernel)
   - The phase kernel SPLITS the eligibility, which dilutes it
   - But even without phase (G_m = 1/M), we underperform because we normalize differently

3. The real e-prop update: dW_ij = learning_signal_i * eligibility_ij
   - learning_signal = error projected through random feedback
   - This is EXACTLY what we do in the no-phase case (collapsing M bins)

KEY INSIGHT: The problem is likely that:
- Our eligibility has M bins each with 1/M weight, so total eligibility = sum of bins = correct
- BUT the CREDIT also splits into M bins, so we get (1/M) * (1/M) * M = 1/M attenuation!

REVISED ALGORITHM IDEA — "Phase-Resonant Eligibility" (PRE):
Instead of SPLITTING eligibility by phase, use phase to MODULATE the eligibility decay rate.
- When pre-post phase alignment is favorable, eligibility decays slower (longer memory)
- When alignment is unfavorable, eligibility decays faster (forgets)
- This creates frequency-selective temporal credit windows without diluting the signal
- Different neurons, oscillating at different frequencies, naturally specialize in
  different temporal delays

Update rule:
  lambda_ij(t) = lambda_base + delta_lambda * cos(phi_i(t) - phi_j(t))
  e_ij(t) = lambda_ij(t) * e_ij(t-1) + post_deriv_i * pre_j
  dW_ij = L_i * e_ij  (at error time)

This way:
- When i and j are in-phase: lambda_ij is HIGH → long memory → credits long-ago events
- When i and j are anti-phase: lambda_ij is LOW → short memory → credits recent events
- Different neuron pairs with different omega_i, omega_j naturally create different
  phase relationships that rotate over time, automatically scanning temporal offsets

This is MUCH simpler, doesn't dilute the signal, and creates a natural frequency-to-timescale
mapping. It's also more biologically plausible: phase-dependent modulation of synaptic decay.
