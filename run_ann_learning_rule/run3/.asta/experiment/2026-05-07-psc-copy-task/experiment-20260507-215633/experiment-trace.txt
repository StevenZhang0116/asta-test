Top-Level Task: Implement and test the PSC (Predictive Self-Correction) learning rule for RNNs on the copy task.

ALGORITHM:
PSC avoids backward propagation entirely. Each neuron has:
1. Main dynamics: h_t = tanh(W_rec * h_{t-1} + W_in * x_t + b)
2. Prediction compartment: p_i(t) = (1-beta)*p_i(t-1) + beta*(W_pred[i,:] @ h(t-1))
   This predicts the neuron's own activity from lateral connections.
3. Prediction error: delta_pred_i(t) = h_i(t) - p_i(t)
4. Eligibility trace: e_ij(t) = lambda*e_ij(t-1) + h_j(t-1)*dtanh_i(t)
5. Output error (only at output timesteps): err_i(t) = (y - target) projected back via W_out^T to hidden
6. Credit signal: s_i(t) = gamma*delta_pred_i(t) + (1-gamma)*output_err_i(t)
   (output_err_i is 0 except during output timesteps)
7. Oscillatory gate: gate(t) = max(0, sin(2*pi*t/T_theta))
8. Weight update: Delta_W_rec_ij = -lr * s_i(t) * e_ij(t) * gate(t)
9. Prediction weight update: Delta_W_pred_ij = -lr_pred * delta_pred_i(t) * h_j(t-1)

Use Adam momentum for weight updates.

EXPERIMENT:
- Task: Copy task — input 8 binary values, wait 10 blank steps, reproduce 8 values
- Architecture: Vanilla RNN, hidden size 128  
- Compare 4 methods:
  (a) BPTT (gold standard)
  (b) PSC with oscillatory gating (our method)
  (c) PSC WITHOUT oscillatory gating (ablation: always consolidate, gate=1 always)
  (d) FA (feedback alignment baseline, from previous experiments)
- Training: 5000 iterations, batch size 32
- PSC hyperparameter grid search (pick best per method):
  - lr: {0.001, 0.005, 0.01}
  - beta (prediction decay): {0.1, 0.3}
  - gamma (prediction vs output weight): {0.3, 0.5, 0.7}  
  - lambda (eligibility decay): {0.9, 0.95}
  - T_theta (oscillation period in timesteps): {10, 20}
  - lr_pred (prediction learning rate): 0.01
- For the grid search: do a quick 1000-iter run for each combo, pick top 3 configs, then run full 5000 iters
- Metrics: Final MSE, bit accuracy, convergence speed

IMPORTANT IMPLEMENTATION NOTES:
- W_pred is a SEPARATE weight matrix (128x128) for prediction, initialized randomly
- W_pred is learned via simple Hebbian prediction error rule (self-supervised)
- The main W_rec update uses the CREDIT SIGNAL (s_i) not the raw prediction error
- Output weights W_out are updated using standard (output_error * h_t) regardless of method
- Use grad clipping (norm 1.0) for stability
