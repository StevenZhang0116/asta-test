Background Knowledge for Step 3: H6 - Predictive Self-Correction with Phase-Modulated Consolidation (PSC)

== MOTIVATION ==
Our previous experiment (Step 2) showed that using forward weights W for backward credit propagation (OPCA) FAILS — performing worse than random feedback alignment. The core problem: backward propagation through ANY matrix (W, W^T, or random B) is an inherently non-local, non-biological operation.

NEW APPROACH: Instead of propagating error backward, have each neuron PREDICT its own future contribution to error using only FORWARD dynamics and LOCAL information. The oscillatory phase then gates when these predictions are evaluated and consolidated.

== ALGORITHM: PSC (Predictive Self-Correction) ==

Each neuron maintains:
1. A "prediction compartment" p_i(t) that predicts the neuron's own future error contribution
2. An "eligibility trace" e_ij(t) marking recent synaptic co-activity
3. A "consolidation flag" that activates during specific oscillatory phases

The key insight: A neuron's future contribution to output error is correlated with how much its activity deviates from what would be "expected" given the current input context. This deviation can be computed LOCALLY.

== FORMAL DEFINITION ==

Forward dynamics (same as standard RNN):
  a_t = W_rec * h_{t-1} + W_in * x_t + b
  h_t = tanh(a_t)
  y_t = W_out * h_t + b_out

Prediction compartment (runs in parallel, LOCAL computation):
  Each neuron i has auxiliary variable p_i tracking "predicted activity":
  p_i(t) = (1-beta) * p_i(t-1) + beta * [W_pred_row_i * h(t-1)]

  where W_pred is a LOCAL prediction weight (each neuron predicts itself from neighbors)
  The prediction error: delta_pred_i(t) = h_i(t) - p_i(t)

  This prediction error is a LOCAL signal — it tells neuron i "how surprising is my current activity given recent history?"

Oscillatory modulation:
  phi(t) = sin(2*pi*t/T_theta)  [theta oscillation]

  Consolidation window: when phi(t) > threshold (e.g., > 0.5), plasticity is enabled
  Outside consolidation window: only eligibility traces accumulate

Learning rule:
  e_ij(t) = lambda * e_ij(t-1) + h_j(t-1) * dtanh_i(t)  [eligibility trace, decaying]

  At output time steps (when loss is available):
    output_error_i = (y_i - target_i) * W_out_ij  [projected output error, for output neurons only]

  At all time steps, the "credit signal" for neuron i is:
    s_i(t) = gamma * |delta_pred_i(t)| * sign(delta_pred_i(t)) + (1-gamma) * output_error_i(t)

    where output_error_i(t) = 0 for non-output time steps (or during delay period)
    and gamma controls the balance between predictive and output-driven learning

  Weight update (only during consolidation window):
    Delta W_ij += -lr * s_i(t) * e_ij(t) * gate(phi(t))

    where gate(phi(t)) = max(0, sin(2*pi*t/T_theta))

  Prediction weight update (always active, self-supervised):
    Delta W_pred_ij += -lr_pred * delta_pred_i(t) * h_j(t-1)  [standard Hebbian prediction learning]

== WHY THIS MIGHT WORK ==

1. NO BACKWARD PROPAGATION: Credit is assigned via forward predictions, not backward error flow
2. LOCALITY: Each neuron only uses its own activity, its prediction, and its eligibility trace
3. OSCILLATORY GATING: Provides temporal structure to consolidation (biologically grounded in theta)
4. SELF-SUPERVISED PREDICTION: The prediction compartment learns WITHOUT external error signals
5. OUTPUT ERROR as ANCHOR: At output time steps, actual error is available and anchors the learning

The biological story:
- Prediction compartment = apical dendrite computing top-down expectation
- Prediction error = dendritic calcium signal (surprise)
- Eligibility trace = synaptic tag (calcium/CaMKII dependent)
- Oscillatory gate = theta-dependent plasticity window (hippocampal LTP is theta-gated)
- Consolidation = synaptic tagging and capture during specific oscillatory phases

== WHAT MAKES THIS GENUINELY NOVEL ==

1. Prior predictive coding work predicts INPUTS to a layer from above. We predict a neuron's OWN activity from its LATERAL connections within the same recurrent layer.
2. Prior oscillatory work separates encoding/retrieval (Hasselmo SPEAR). We separate prediction-evaluation/consolidation.
3. The combination: "local lateral self-prediction" + "oscillatory consolidation gating" + "eligibility-trace credit" has not been proposed.
4. It's NOT just feedback alignment + oscillations (which we tested and it barely helps).
5. It's NOT just predictive coding in time (which uses backward prediction errors across layers).

== EXPERIMENT ==

Test PSC on the same copy task as before for direct comparison:
- Copy task: 8 bits, 10-step delay
- Vanilla RNN, hidden size 128
- Compare: BPTT, PSC (our new method), FA (baseline), OPCA (previous attempt)
- Training: 5000 iterations, batch size 32
- Hyperparameter search:
  - Learning rate: {0.001, 0.005, 0.01}
  - beta (prediction decay): {0.1, 0.3, 0.5}
  - gamma (prediction vs output balance): {0.3, 0.5, 0.7}
  - lambda (eligibility decay): {0.9, 0.95}
  - T_theta (oscillation period): {10, 20}

Also test: PSC WITHOUT oscillatory gating (always consolidate) to isolate the contribution of oscillatory modulation.
