# Research Logbook

## Step 1: Literature Novelty Search for H1 and H2

Conducted a comprehensive literature search to assess the novelty of two candidate learning algorithms: H1 (Dendritic Self-Prediction for Temporal Credit) and H2 (Oscillatory Phase-Gated Credit Assignment). Searched Semantic Scholar for papers on dendritic compartments + temporal credit, predictive learning rules, oscillatory phase separation for learning, and related topics. Found that H1 has significant overlap with recent work (temporal predictive coding 2026, predictive e-prop 2026, Saponati & Vinck 2023) giving it ~55% novelty. H2 is more novel (~65%) — while Hasselmo's SPEAR model separates encoding/retrieval by theta phase, no one has proposed using oscillatory phases to multiplex forward computation and temporal credit assignment through the same weights. Decision: pursue H2 as primary hypothesis. Full report in docs/novelty_assessment.md.

## Step 2: OPCA Algorithm Formalization and Experimental Test

Formalized the OPCA (Oscillatory Phase Credit Assignment) algorithm mathematically and tested it on the copy task (8 bits, 10-step delay, vanilla RNN 128 hidden units, 5000 iterations). Compared against BPTT, Feedback Alignment (random B), RFLO, and OPCA-alpha (learned damping). Key result: OPCA (using forward weights W for credit propagation) performs WORSE than feedback alignment with random B (62.4% vs 79.7% accuracy). BPTT achieves 100%. The OPCA-alpha variant learns to reduce damping to ~0.047, effectively abandoning temporal credit in favor of nearly-local learning (80.6% accuracy). Conclusion: the "same weights for both directions" idea doesn't work — W is not a useful substitute for W^T in credit propagation. Need to pivot to an approach that avoids backward propagation entirely. Full experiment in .asta/experiment/2026-05-07-opca-copy-task/.

## Step 3: PSC (Predictive Self-Correction) Algorithm Design and Test

Designed a new algorithm (PSC) that avoids backward propagation entirely. Each neuron has a prediction compartment that predicts its own activity from lateral connections, creating a local "surprise" signal. Combined with eligibility traces and output error feedback, this provides temporal credit without any backward information flow. Tested two variants: PSC-Osc (with oscillatory gating of plasticity) and PSC-NoGate (always consolidate). Results: PSC-NoGate achieves 76.4% bit accuracy (MSE=0.1575), substantially outperforming FA baseline (50.8%) and the oscillatory-gated variant (51.7%). Key finding: oscillatory gating HURTS rather than helps — it restricts plasticity to ~50% of timesteps, halving the effective learning signal. PSC-NoGate is the most promising bio-plausible algorithm so far, using only local signals (eligibility traces + output error + self-prediction), though a major gap to BPTT (100%) remains. Full experiment in .asta/experiment/2026-05-07-psc-copy-task/.
