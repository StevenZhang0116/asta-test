# Research Logbook

## Step 1: Literature Novelty Search for H1 and H2

Conducted a comprehensive literature search to assess the novelty of two candidate learning algorithms: H1 (Dendritic Self-Prediction for Temporal Credit) and H2 (Oscillatory Phase-Gated Credit Assignment). Searched Semantic Scholar for papers on dendritic compartments + temporal credit, predictive learning rules, oscillatory phase separation for learning, and related topics. Found that H1 has significant overlap with recent work (temporal predictive coding 2026, predictive e-prop 2026, Saponati & Vinck 2023) giving it ~55% novelty. H2 is more novel (~65%) — while Hasselmo's SPEAR model separates encoding/retrieval by theta phase, no one has proposed using oscillatory phases to multiplex forward computation and temporal credit assignment through the same weights. Decision: pursue H2 as primary hypothesis. Full report in docs/novelty_assessment.md.
