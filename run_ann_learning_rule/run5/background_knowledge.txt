BACKGROUND KNOWLEDGE FOR STEP 5: RFLO and e-prop baselines on copy task

TASK
----
Reproduce two biologically-plausible learning rule baselines — **RFLO** (Murray 2019)
and **e-prop** (Bellec et al. 2020) — on the exact same copy task and architecture
used for the Step-3 BPTT baseline. This gives the "biologically-plausible reference":
STC-Credit (Step 6) needs to at least match these to be interesting.

TASK / ARCHITECTURE (IDENTICAL TO STEP 3 BPTT BASELINE)
-------------------------------------------------------
- Vanilla Elman RNN, explicit recurrence: h_t = tanh(W h_{t-1} + U x_t + b), ŷ_t = V h_t
- Hidden size N = 128
- Input dim 10 (8 symbol one-hots + blank + go)
- Output dim 8
- Sequence length 15: symbols t=1..5, blanks t=6..9, blank+go t=10, target output t=11..15
- Loss: cross-entropy only on output timesteps
- Batch size 64; 3000 training steps; eval every 100 on 1000 held-out sequences
- Device: GPU if available (torch.cuda.is_available()), else CPU; log device at start

RULE 1 — RFLO (Murray 2019, eLife)
----------------------------------
The canonical local online rule for vanilla rate RNNs. For each recurrent synapse W_{ij}
and input synapse U_{ij}:

Eligibility trace:
  p^W_{ij}(t) = (1 - α) p^W_{ij}(t-1) + α · φ'(u_i(t)) · h_j(t-1)
  p^U_{ij}(t) = (1 - α) p^U_{ij}(t-1) + α · φ'(u_i(t)) · x_j(t)

Feedback (fixed random; no weight transport):
  ℓ_i(t) = (B e(t))_i, where B ~ N(0, 1/sqrt(n_y)) fixed; e(t) = ŷ(t) - y(t)
  (ℓ_i applies only at output timesteps t=11..15.)

Weight update (per-step, online, continuous modulation):
  ΔW_{ij}(t) = -η · ℓ_i(t) · p^W_{ij}(t)
  ΔU_{ij}(t) = -η · ℓ_i(t) · p^U_{ij}(t)

Readout (local delta rule):
  ΔV_{ij}(t) = -η_V · e_i(t) · h_j(t) at output timesteps

Hyperparameters (starting defaults):
  α = 0.1 (matches planned STC-Credit tag decay)
  η = 3e-3 for RFLO recurrent/input weights (smaller than Adam; RFLO is typically pure SGD)
  η_V = 1e-3 for readout
  Use plain SGD (no Adam) for the local rule — this is standard and keeps the comparison
  clean to what a neuron can locally compute.

RULE 2 — e-prop (Bellec et al. 2020, Nat Comm)
----------------------------------------------
For a vanilla rate RNN (not LSNN; we are running the rate version for apples-to-apples
comparison with BPTT and RFLO) e-prop adds to RFLO a learning-signal derivation: instead
of using only the instantaneous ℓ_i, e-prop uses an "exact immediate" contribution of
each synapse to the neuron's own output. For rate RNNs this reduces to:

Eligibility trace (identical recursion to RFLO, but with pre-synaptic history):
  For recurrent synapses: same as RFLO (p^W_{ij} update).
  For input synapses:     same as RFLO (p^U_{ij} update).

Learning signal (key difference vs RFLO): the learning signal is the readout-pathway
gradient with random feedback — i.e., ℓ_i(t) = (B e(t))_i, same as RFLO for rate RNNs
with a linear readout. (In spiking LSNN e-prop uses L_j = sum_k B_{jk} (ŷ-y)_k.)

Weight update:
  ΔW_{ij}(t) = -η · ℓ_i(t) · p^W_{ij}(t)

In the rate-RNN / linear-readout case, **e-prop and RFLO become nearly identical**:
both use a fixed-random feedback learning signal × a low-pass eligibility trace. The
main distinctions in the original e-prop paper are (i) the spiking-neuron surrogate
gradient, and (ii) the derivation of the eligibility trace from the true local
Jacobian, which for vanilla rate RNNs coincides with the RFLO trace.

Given this, we will run TWO variants to disambiguate:
  - "RFLO-strict": fixed α = 0.1, plain SGD.
  - "e-prop-rate": the same but with a *learned* readout (so V is updated locally
    with an exact supervised delta; the recurrent side uses identical math to RFLO).
    This matches Bellec et al.'s formulation when applied to a rate RNN.

If the resulting numbers are essentially identical, we will report one rule and
note that for a rate-RNN / linear-readout the two rules collapse.
