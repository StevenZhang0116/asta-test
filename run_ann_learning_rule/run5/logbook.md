## Step 2: Novelty-informed design of STC-Credit

Specified H1 as **STC-Credit** — a two-timescale synaptic-tagging-and-capture rule for RNNs — in `design_step2.md`. The rule maintains an RFLO-style fast eligibility tag τ_{ij} = (1−α)τ_{ij} + α·φ'(u_i)·h_j at each synapse, computes a per-neuron surprise s_i from a random-feedback teaching signal ℓ_i = B_i·e, and gates weight updates by a threshold: Δw_{ij} = −η · 1{s_i > θ} · ℓ_i · τ_{ij}. Ran a targeted novelty audit (7 Semantic Scholar queries) and compared to the closest near-matches; overall verdict: novel. The closest predecessor is Izhikevich 2007 (continuous, RL, not thresholded, not RNN-supervised); other near-adjacencies are Luboeinski-Tetzlaff 2020 (STC in RNNs for memory consolidation, different task), Rombouts et al 2015 (attention-gated eligibility, RL), and the RFLO/e-prop/ModProp family (all continuous modulation). Added 5 new near-match references to `references.bib` (73 entries total). Verified design_step2.md renders cleanly with pandoc+citeproc — all cites resolve. Plausibility checklist: passes all 5 desiderata. Falsifiability: three explicit signatures (F1 chance-level on copy-10, F2 continuous-dominates ablation, F3 dense-gating empirics). Confidence in H1 raised from ~35% to ~40%.

Ran 7 targeted SNN-literature queries (event-driven plasticity, gated STDP, PRP plasticity, sparse plasticity events, STC+SNN credit, surprise-gated plasticity, threshold-crossing gate) to close the residual novelty gap flagged in design_step2.md §4.3. Added a new Step-6 ablation (AGMP-style activity-gated baseline) to isolate the *error-driven* aspect of STC-Credit's gate. H1 confidence raised ~40% → ~45%.

## Step 5: RFLO / rate-e-prop baseline on copy task

Invoked run-experiment (Panda) with a concise --task string plus the run5/background_knowledge.txt file (addressing the Step-3 methodology feedback). Declared an up-front deviation: for a rate RNN with linear readout, RFLO and rate-version e-prop produce identical updates, so one experiment covers both rules. Panda produced the canonical artifact set in `.asta/experiment/2026-05-10-rflo-eprop-copy/`. Swept η ∈ {1e-4, 3e-4, 1e-3, 3e-3, 1e-2} after the default (3e-3) underperformed. **Result: best η=1e-4 → 55.3% per-symbol accuracy, 2.7% sequence-level accuracy, 90% never crossed in 3000 steps.** Default η=3e-3 gave 34.1%. Wall-clock 0.85s/100 steps on A100 — basically the same as BPTT's 0.82s/100 steps, so the gap (BPTT 100% vs RFLO 55.3% = 44.7 pp per-symbol) is a credit-assignment gap, not a compute gap. Caveats: single seed, best config had not converged at step 3000, readout η_V unsept. **Bottom line: the credit-assignment floor STC-Credit must close is substantial.** Next: Step 6 — STC-Credit implementation with five ablations.
